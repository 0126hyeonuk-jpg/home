# 찐말랑 하우스

SH·LH·청년안심주택 3개 기관 각각의 신혼부부 대상 입주자모집공고를 최신순 리스트로 한 페이지에서 확인하는 웹페이지입니다. 기관마다 **오늘 기준 최근 2개월 이내** 게시된 공고를 모두 보여주며(상시모집/수시모집 항목은 예외), 1차/2차 같은 일괄공고 외에 개별 단지 공고도 함께 표시됩니다. 2개월 내 신규 공고가 없는 기관은 그 사실을 그대로 안내합니다.

**페이지: https://claude.ai/code/artifact/6d5de43c-c9ad-4be1-b77e-8f19a7cc185b**

## 자동 갱신

루틴 **"찐말랑 하우스 자동 갱신"** (trigger `trig_0178msj6c8k66odTYRusH6LS`)이 매일 오전 10시(KST, cron `0 1 * * *` UTC)에 실행되어 WebSearch로 3개 사이트의 최신 신혼부부 대상 공고를 다시 확인하고, 위 기준 충족 여부와 함께 페이지를 갱신합니다. 기존에 등록된 "주택청약 새 공고 알림" 루틴(매일 10시, 4개 사이트 확인 후 이메일 발송)과 같은 시각에 맞췄습니다.

- 이 루틴은 Claude Code(코드 저장소) 환경에서 실행되며, 이 환경은 soco.seoul.go.kr/apply.lh.or.kr/i-sh.co.kr로의 직접 접속(WebFetch)이 막혀 있어 WebSearch로만 정보를 모읍니다. 그래서 검색으로 노출되지 않는 단지별 세부 수치(전용면적, 구별 세대수)는 "확인 필요"로 표시될 수 있습니다.
- 공고문 PDF를 직접 열어 정확한 수치까지 확인하려면, 브라우저 접근이 가능한 별도의 Cowork 세션(사람이 직접 대화하며 컴퓨터 사용 권한을 승인하는 세션)이 필요합니다. 백그라운드 루틴만으로는 PDF 바이너리/JS 다운로드를 안정적으로 열람하거나 그 결과를 이 저장소로 가져올 방법이 없었습니다(자세한 내용은 대화 참고).

`data/latest.json`은 최초 구축 시점(2026-08-30)의 스냅샷 기록이며, 실제 최신 정보는 위 페이지 링크가 항상 최신 상태입니다(자동 갱신은 별도 환경에서 웹페이지만 갱신하며 이 저장소에는 반영되지 않습니다).

## 인터랙션

각 공고를 클릭하면 외부 사이트로 바로 이동하지 않고, 페이지 안에서 팝업(모달)으로 "PDF·공고문 분석 인사이트"가 뜹니다. 이 텍스트는 페이지 하단 `<script>`의 `INSIGHTS` 객체에 공고별로 저장돼 있으며, 자동 갱신 시 목록과 함께 갱신됩니다. 팝업 안의 "원문 공고 열기" 버튼을 눌러야 실제 사이트로 이동합니다.

## 청약신청일 캘린더 · D-day

페이지 상단에 접수기간·청약시작일이 확인된 공고만 월별 캘린더로 보여줍니다(데이터는 `EVENTS` 배열, 오늘 날짜는 `TODAY` 상수). 캘린더 위에는 같은 데이터로 자동 계산되는 D-day 칩 스트립(`renderDdayStrip`)이 있어 "D-2", "접수중", "마감"을 한눈에 볼 수 있습니다. 날짜 막대나 D-day 칩을 클릭해도 같은 인사이트 팝업이 뜹니다. 접수 일정이 불확실한 공고는 캘린더에 억지로 넣지 않고 `UNDATED_NOTE`에 안내만 남기며, 자동 갱신 때 `INSIGHTS`·`EVENTS`·`TODAY`를 함께 갱신하도록 루틴에 지시해뒀습니다(D-day는 EVENTS/TODAY에서 자동 계산되므로 별도 데이터가 없습니다).

## 신청 준비서류 체크리스트

페이지 하단에 신혼부부 청약에 공통적으로 자주 쓰이는 서류 목록(신분증, 등본, 혼인관계증명서, 소득·자산 증빙 등)을 접이식 체크리스트로 넣었습니다. 체크 상태는 보는 사람의 브라우저(localStorage)에만 저장되며, 공고 데이터와 무관한 고정 콘텐츠라 자동 갱신 루틴은 이 섹션을 건드리지 않습니다.

## 참고

- 이 페이지에 표시된 조건 중 "확인 필요"로 표시된 항목은 공개된 정보만으로 확정하지 못한 값이며, 신청 전 반드시 각 기관의 공고문 원문을 확인해야 합니다.
- 접수기간이 지난 공고는 다음 차수가 게시될 때까지 최근 공고로 표시될 수 있습니다.
